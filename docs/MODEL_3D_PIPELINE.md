# Pipeline 3D — MenuAR

1. Preparar prato estático, luz difusa, superfície neutra
2. 40–80 fotos (volta baixa/média/superior)
3. Informar dimensões em cm
4. Fotogrametria local (Object Capture / Blender)
5. Limpar mesa/fundo, otimizar, escalar
6. Exportar GLB + USDZ + poster
7. Meta &lt; 2 MB (limite publicação 5 MB)
8. Testar iPhone/Android/desktop
9. Aprovação do restaurante
10. Publicar

Ferramenta auxiliar: `tools/photogrammetry`.
